# STed2 plus for Mac - 再ビルド、復元、機能拡張
=============

2003 年から 2015 年までメンテナンスされていた「STed for Aqua」は実験的なリリースで、STed2 のすべての機能は入っていませんでした。最終版は Intel i386 のみに対応しており、現在の macOS では動きません。2025 年に、現代の環境（x86_64/arm64）へ向けた再構築を始めました。当初は個人的なフォークに過ぎませんでしたが、2026 年には AI によるコード解析を用いた、本格的な復元プロジェクトになっています。互換性は保ったうえで細かな拡張を加えたため、名称を「STed2 plus for Mac」と改めました。

## 機能
Human68k 版がコンパニオンプログラム RCD.x を必要とし、UNIX 移植版が Timidity++ または aplaymidi と FluidSynth を必要としたのとは異なり、これは単体で動くアプリケーションです。シーケンサを内蔵し、2種類のシンセサイザを組み込んでいます。

#### シーケンサと STed2 のシステム
- カモンミュージックのレコンポーザ互換の内蔵シーケンサ（永田さんによる実装）
- STed2 はもともと X68000上で単独のシステムとして動くように作られていたため、シーケンサとしての基本機能がいくつか欠けていました。今回の更新では、MIDI の外部クロックによるスレーブ動作と、MIDI リアルタイムメッセージ（Start、Stop、Continue）およびソングポジションポインタの認識を追加しました。この実装は MIDI リアルタイムメッセージの仕様に沿っているため、MIDI クロックを送らない MIDI コントローラには対応しません。将来的に対応を検討することはありますが、その場合は HUI や MCU のような、まったく別の技術が必要になります。
- オリジナルの STed2 は Roland GS と SC-55 / SC-88 / 88Pro / 8850 シリーズとの互換を主眼にしていました。この版では GM1、GM2、XG への対応を追加しています。さらに、GM 互換の音源チップ「DREAM SAM2695」にも対応しました。製造元の DREAM は、2020 年代に入っても GM チップを作り続けている唯一の会社です。
- 現代の AI 解析を使い、脆弱性の洗い出しと除去を行いました。`long` を `int32_t` に置き換えるなど変数の大きさを固定化し、`strcpy` には長さの上限を付けました。さらに、Human68k の時代から放置されていた、バッファサイズが小さすぎる固定長の配列を見つけ、十分な大きさに広げました。
- ファイルの読み込みと書き出しは、RCP、R36、MID に加えて、ABC 記譜にも対応しました。ABC は楽曲生成 AI「YuE2」やライブラリ「music21」で広く使われており、汎用の生成 AI（Gemini、ChatGPT、Grok など）に作曲を頼んだときにも出力できる形式です。AI の出力をテキストファイルとして保存し、拡張子を「.abc」にして読み込めます。複数トラックと GMの楽器割り当てを含む譜面を書き出すこともできます。

#### DLS シンセと AMY シンセ
- 各種 SoundFont を読み込める Apple DLS シンセサイザ。macOS の所定のディレクトリ「~/Library/Audio/Sounds/Banks」にある拡張子 .sf2 または .dls のファイルが、一覧に表示されます。
- 「AMY」はオープンソースのシンセサイザで、JUNO-106 や DX7 互換の音を模倣でき、同時に 16 パートのマルチティンバー音源としても動作します。
- DLS シンセ 2 台と AMY シンセ 1 台のうちから選び、2 系統の MIDI 出力に割り当てることで、最大 2 台のシンセを同時に使えます。それぞれが 16 パートのマルチティンバー音源なので、合計で最大 32 パートを使えます。もちろん、MIDI 出力に並んでいる他の MIDI 機器へ送ることもできます。使っていない内蔵シンセは、切り離すと動作を止めるので、CPU を消費しません。
- AMY シンセは、画面を持たないヘッドレスのシンセサイザです。本来は音色を編集する過程も楽しいものですが、現在のリリースでは JUNO のプリセット 128 種と DX7 のプリセット 128 種から選ぶところまでに限っています。システムエクスクルーシブ（SysEx）は JUNO や DX7 とは異なるため、専用のエディタを作るか、元の SysEx との互換層を実装すれば、既存のエディタを使えるようにできます。これは今後の課題として残します。
- 集めてきた SoundFont に対応するパッチリストが無いと、STed2 では音色を選びにくい、という問題に対して、SF2 ファイルを解析して STed2 の音源定義ファイルを自動生成するメニューコマンドを追加しました。さらに、MIDI ポート A と B で別の SoundFont を読み込む場合に備え、UNIT SEL を拡張し、ポートごとに独立した音源設定を持てるようにしました。SF2 の解析には、オープンソースの TinySoundFont を使っています。

#### 追加のトータルエフェクト
- 統合ミキサーと、一式のトータルエフェクトを内蔵しています。DLS シンセから送られるリバーブバスに加え、2 台のシンセのバランスを取るミキサー、その後段のトータルエフェクト 3 種、最後にマスターボリュームがあります。マスタリングを想定したもので、耳にきつく聴こえがちな SoundFont を整えるためのものです。構成は High / Low の EQ、リバーブ、リミッタで、いずれも macOS に内蔵されたモジュールを使っています。音量を含め、これらの設定は MIDI からは操作できません。無効にもできるので、好みに応じて使ってください。

#### 必要な macOS のバージョン
- 対応 OS: macOS 12.0 Monterey 以降。Intel と Apple Silicon の両方に対応しています。

## 短期の目標
第一の目的は、現代の macOS 上で STed2 の機能を復元することです。復元したソフトウェアが、Human68k 版の STed2 と同じように、再生、入力、録音のできるシーケンサとして動作することを目指しています。

## 中長期の目標
このプロジェクトを土台に、他のオペレーティングシステムへの対応を広げることを目指しています。ハードウェアとアプリケーションの間にハードウェア抽象化層（HAL）を置き、さまざまな環境で動く移植しやすいシステムにすることを計画しています。
