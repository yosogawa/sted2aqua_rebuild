* Editing the define file lets you support other modules.


Commands you can use in a define file

  #module=      Model name of the module in use (for display) (up to 22 characters)

  #id=          Model ID of the module in use (for internal processing)

                        =CM64   Match the PART3 (PCM) patch to the CM-64 defaults.
                                Send the control data (.CM6) to the module.
                                Before playback, set the CM-64 master volume and
                                similar parameters.
                                Set the panel tone names to CM mode.
                                (For an MT-32 or CM-32x, set CM64 as well.)

                        =SC55   Set the panel tone names to GS mode.
                                (For a CM-300, SC-155, SC-33, or SC-55mkII, set
                                SC55 as well.)

                        =SC88   Set the panel tone names to GS mode.
                                Supports switching the display between 88map and
                                55map by BANK LSB. (Use #gm_pbank/#gm_rbank for
                                the 55 map.)

                        For any other module, set some suitable text.
                        (U220, 05RW, TG300, and so on.)

                        If omitted, the driver setting from before startup is used.

  #mute=        Which module to mute

                        =CM64   Mute the CM-64. (The SC-55 mute is cleared.)
                                (For an MT-32 or CM-32x, set CM64 as well.)

                        =SC55   Mute the SC-55. (The CM-64 mute is cleared.)
                                (For a CM-300, SC-155, SC-33, SC-55mkII, or SC-88,
                                set SC55 as well.)

                        =OFF    Clear mute mode

                        If omitted, the driver setting from before startup is used.


  #group=       Assign a tone list to each channel.

                        From the next line, list the part numbers.
                        You can set 32 channels.

                            0=unused (NoUse)
                        1 to 15=part1 to part15

                                part 1 to 3(4) (CM-64 only)
                                part 7 (GS/GM format bank support)
                                part 8 (GS/GM rhythm bank support)
                                part 9 (GS/GM format bank support)
                                part10 (GS/GM rhythm bank support)
                                part11 (GS/GM format bank support)
                                part12 (GS/GM rhythm bank support)
                                part13 (GS/GM format bank support)
                                part14 (GS/GM rhythm bank support)

                        #group_a= ch.A1-A16
                        #group_b= ch.B1-B16

  #gs_mode=     Set the bank mode of part7/part8.
  #gm_mode=     Set the bank mode of part9/part10.
  #gx_mode=     Set the bank mode of part11/part12.
  #gy_mode=     Set the bank mode of part13/part14.

                bit 0 = 0  Disable capital fallback.
                        1  Enable capital fallback.

                bit 1 = 0  Disable capital fallback for RHYTHM.
                        1  Enable capital fallback for RHYTHM.

                bit 2 = 0  Switch banks with BANK MSB.
                        1  Switch banks with BANK LSB.

  #gs_pbank     Assign the tone lists for part7's banks.
  #gm_pbank     Assign the tone lists for part9's banks.
  #gx_pbank     Assign the tone lists for part11's banks.
  #gy_pbank     Assign the tone lists for part13's banks.
                        (Supports switching by control change 0/32 (BANK MSB/LSB).)

                        From the next line, list the part numbers.
                        You can set 128 banks.

  #gs_rbank     Assign the tone lists for part8's banks.
  #gm_rbank     Assign the tone lists for part10's banks.
  #gx_rbank     Assign the tone lists for part12's banks.
  #gy_rbank     Assign the tone lists for part14's banks.
                        (Supports switching by program change.)

                        From the next line, list the part numbers.
                        You can set 128 banks.

  #gs_pgroup
                Set which bank part corresponds to each bank LSB.
                        (Supports a bank switch that specifies bank MSB and
                        bank LSB together.)
                        (You can specify 7, 9, 11, and 13.)

  #gs_rgroup
                Set which bank part corresponds to each bank LSB.
                        (Supports a bank switch that specifies program and
                        bank LSB together.)
                        (You can specify 8, 10, 12, and 14.)

  #rhy_as=      Set the initial data for rhythm assign.

                        After the command, write the sound-test ch. and prog.no.
                        From the next line, set a rhythm name, KEY No., and GATE
                        TIME as one set. You can set 32 sounds.

                        (ch.(1 to 32), prog.(0 to 127, -1=off), bank l.(0 to 127, -1=off),, vel)
                        (A rhythm name is up to 14 characters.)

  #part=        Set the tone names for each part.

                        After the command, write the part number, title, header,
                        and offset. From the next line, specify the tone names.
                        One part can hold 128 tones.
                        (A tone name is up to 12 characters. Only a GS/GM rhythm
                        part may use 14.)

                                part 1 to 3(4) (CM-64 only)

                                part 7 (GS/GM format bank support)
                                part 8 (GS/GM rhythm bank support)

                                part 9 (GS/GM format bank support)
                                part10 (GS/GM rhythm bank support)

                                part11 (GS/GM format bank support)
                                part12 (GS/GM rhythm bank support)

                                part13 (GS/GM format bank support)
                                part14 (GS/GM rhythm bank support)

                                part16 to 400 (bank only)

                        (part no, list title (16 bytes), header (6 bytes), offset
                        from the start)

  #card=        Set the tone names for each CM-64 card.

                        After the command, write the card number, card name, and
                        title. From the next line, specify the tone names.
                        One card can hold 128 tones. (A tone name is up to 10
                        characters.)
                        (The tone names are registered in part16 to 31.)

  #card_no=     Specify the card the CM-64 uses.
                        (The tone names are registered in part4.)

  #lsp_wait=    Increase the wait when point play sends the last parameters.
                        (0 to 16 = wait x 0 to 16 / -1 = do not send the last parameters)

                                = 1 to 16  Multiply the wait by this value
                                = 0        Insert no wait
                                =-1        Do not send the last parameters

  #defoff       End of the define commands

  #end          End of the define file


* If you have entered a tone list for a card or module that is not in this file,
* please send it. It will be added to the file. Thank you.
*                                                                       TURBO
