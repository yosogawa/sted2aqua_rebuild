《Features》

    This program is a MIDI sequencer for the SHARP X680x0 series.

    It can record in real time, enter steps, and edit in the RCP format of
    Recomposer/98 v2.5F. There are 36 tracks. With enough memory, up to
    589,356 steps can be edited.

    It needs a MIDI board (SHARP CZ-6BM1 / System Sacom SX-68M), a MIDI
    sound module, and, as the MIDI driver, 'RCD.x' or similar from the MIDI
    playback system [RC] v3.01 or later. (Panel-display playback also needs
    'RCP.x'.)

    (It can also be used with a MIDI adapter on RS-232C, such as the System
    Sacom SX-232C. It can also be used with a POLYPHON MIDI port.)

    (It is aimed mainly at Roland MIDI modules (CM-64/SC-55/SC-88). Other
    modules can be used too, except for some functions.)

    Creating tones for the LA section of a CM-64 or similar also needs
    Timbre Editor 'TE.x' v0.50 or later.

《How to run it》

    Before starting, set the directory for song files
    (.RCP/.R36/.CM6/.TRK/.PRT/.TXT/.REX/.RES/.EXC/.RAS) with the environment
    variable 'RCP_DIR', or with the '-D' option at startup.

    If you do not set one, the current directory is used. If you start the
    program with a filename, the directory is that file's path.

    Part files (.PRT), exclusive files (.REX/.RES/.EXC), and rhythm-assign
    files (.RAS) normally use the same directory as the song files, but you
    can set them with 'PRT_DIR'.

    Also keep RCD.x resident as the MIDI driver, and put RCP.x, TE.x, and
    similar tools on PATH when you need them.

    If you name an .RCP/.R36 file, or an .MDF file, at startup, that file is
    loaded as the program starts.

    (The free memory area must have at least 820K bytes free.)

    (IOCS.x, HIOCS.x, or similar is recommended, to speed up the display.)


  Options ('/' cannot be used in place of '-'.)

        -M<size>        Set the maximum size of one track. <default = 64K byte>
                                        (size = 64 to 256K byte)

                                Sets the maximum size one track may use.
                                (Recomposer/98 v2.5F and similar cannot use a
                                track larger than 64K bytes.)

        -U<size>        Set the maximum size when allocating track buffers.
                                        (size = 64K byte and up)

                                Normally it takes as much as it can from the
                                free area, up to track size times 36. This
                                option sets that limit.

                                If you set it, free memory in the track buffers
                                is not released when a child process runs.

        -W<size>        Set the size of the recording buffer.
                                        (size = 128 to 512K byte)

                                Sets the buffer used for recording. (The default
                                is the track size plus 32K bytes.)

        -F<file>        Name the module define file.

                                The default file depends on the setting in
                                STed2.cnf.

                                To name a file outside the current directory,
                                give the full path.

                                A file in the directory that holds STed2.x can
                                omit the path.

                                Example      sted2 -fsc88

        -B<num>         PCM CARD used to display tone names. (1 to 16)
                                (when cm64.def is in use)

        -D<path>        Set the data directory.

                                If path is omitted, the current directory is set.

        -R              Run point play with the RCD.x function.

                                Normally the start of playback is managed by
                                measure number, so playback starts in a few
                                seconds. If a repeat that crosses measures
                                shifts the measure timing of each track, point
                                play does not work correctly.

                                With this switch, timing is managed by ST, so
                                playback is correct even if the measure numbers
                                have drifted. It uses RCD's search, so there is
                                a wait before playback starts.

        -P              Make panel-display playback the default of the Play
                        command on the main menu. (Swaps the function with
                        [SHIFT] mode.)

        -L              At startup, read the data in the RCD buffer

        -S              On exit, do not send data to the RCD buffer

                                Normally, on exit, the data is sent to the RCD
                                buffer as a backup. This switch cancels that
                                transfer.

                                (If you quit STed during playback, playback
                                stops. With this switch, playback continues.)

        -?              Show the options


                Options can also be set in the environment variable 'STED2'.


  Example

        C:\>set RCP_DIR=D:\RCP\
        C:\>rcd
        X68k RCD:  RC play driver v3.01 Copyright 1990-96 HARPOON,TURBO
        Now resident.
        C:\>sted2
        X68k MIDI Music Composer STed v2.07 Copyright 1990-96 TURBO


《Extensions》

        *.RCP   Song data (18/36 tracks)        (*1)
        *.R36   Song data (36 tracks only)      (*1)
        *.CM6   CM-64 control data              (*1)
        *.GSD   SC-55 control data              (*1)
        *.TRK   Song data, one track
        *.PRT   Song data for a range           (*1)
        *.REX   User exclusive data (all)       (*1)
        *.RES   User exclusive data (one)
        *.EXC   Track exclusive data (text)
        *.RAS   Rhythm assign data

        (*1 compatible with Recomposer/98 v2.5F)
